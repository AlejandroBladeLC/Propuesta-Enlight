# Experiencia Enlight

Prototipo de una propuesta para mejorar la visibilidad y el seguimiento de proyectos de clientes de Enlight.

La demo permite consultar etapas, responsables y actualizaciones de proyectos de ejemplo, además de registrar comentarios e incidentes y confirmar acciones pendientes.

Este es un prototipo para presentar el concepto. Los datos que se ingresan se guardan únicamente en el navegador donde se utiliza; 
todavía no existe una base de datos compartida ni conexión con los sistemas de la empresa. La propuesta puede refinarse y ampliarse en una siguiente etapa.
